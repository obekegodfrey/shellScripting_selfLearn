# Function

A function is a block of code that is reusable and performs operations. Like any other programming language, Shell scripting also supports functions. Functions are popular for the following reasons:
- Help to reuse a piece of code.
- Improve the readability of the program.
- Make the program modular.
make maintenance easier

. A function is a block of code that performs a specific task and which is reusable.
. Functions concept reduces the code length.
. Two ways to define a function.


function function_name
{
    commands/statements
}

function_name()
{
    commands/statements
}
